# JigJoy × daily.dev × Hyperskill Hackathon — rule snapshot

Verified 2026-09-05 from the official event and rules pages.

- Event: <https://build.jigjoy.ai/>
- Official rules: <https://build.jigjoy.ai/rules>
- Build weekend: September 5–6, 2026; worldwide and online.
- Submission deadline: Monday, September 7, 2026 at 09:00 CET / 03:00 ET / midnight Sunday PT.
- Resubmission is allowed until the deadline; the latest entry is judged.
- Teams: solo or up to four people; one entry per team and one team per person.
- Project rule: the substance must be built during the hackathon; existing frameworks, libraries, and boilerplate are allowed.
- Required technology: `@mozaik-ai/core` and two or more concurrent agents.
- Required submission: project name, accessible repository, description, and an explanation of how the agents run concurrently.
- Demo video, live deployment, and screenshots are optional but strongly recommended.
- Judges may exclude a project they cannot open, run, or verify.
- Judging weights genuine concurrency alongside technical execution, creativity, and demo clarity.
- Cash prizes: first $500, second $300, third $200.

The product repository does not submit the competition form. Submission remains a separate operator action.
